---

To run the game, open Launcher.java and run it.

Music from OpenGameArt; can be found here (https://opengameart.org/content/crystal-cave-song18)

No Parents nor Students are present in the base file. Use the "I am a Parent" checkbox and Register Parent on the login screen to create one with your own username and password.

Built to run on Java 21, but tested up to 25.
